# 直播源配置与推荐

LibreTV 的直播频道全部来自外部 M3U 播放列表，项目本身不内置频道。本文档整理部署时可直接使用的配置方式、实测过的公开播放列表，以及自测工具的使用方法。

## 一、配置方式

在 `.env.local`（或部署平台的 `DEFAULT_LIVE_SOURCES` 环境变量）里写 JSON 数组：

```bash
DEFAULT_LIVE_SOURCES=[
  {"name":"VBSKY 综合","url":"https://raw.githubusercontent.com/vbskycn/iptv/master/tv/iptv4.m3u"},
  {"name":"Free-TV 中国","url":"https://raw.githubusercontent.com/Free-TV/IPTV/master/playlists/playlist_china.m3u8"}
]
```

- `name`：显示名，缺省时用 URL 主机名；
- `url`：M3U / M3U8 播放列表地址（必须是 http/https，内网地址默认被 SSRF 防护拦截）；
- `epg`：可选，XMLTV 节目单地址，用于在 `/live` 页展示节目单。

配置后重启服务，进入 `/live` 页即可看到频道，按分组（央视、卫视、地方、电影等）浏览。也可以在 **设置 → 源管理 → 直播源** 里手动添加，效果相同。

## 二、实测播放列表（2026-10-23）

抽样方式：每个列表等距抽取 20–25 个频道，请求分片并检查是否返回非空内容。可达率受网络环境（尤其是运营商和是否支持 IPv6）影响，仅供参考。

| 名称 | 地址 | 频道数 | 抽样可达 | 说明 |
|---|---|---:|---:|---|
| VBSKY 综合 | `https://raw.githubusercontent.com/vbskycn/iptv/master/tv/iptv4.m3u` | 516 | 84% | 央视、卫视、地方台齐全，综合首选 |
| Free-TV 中国 | `https://raw.githubusercontent.com/Free-TV/IPTV/master/playlists/playlist_china.m3u8` | 21 | 95% | 频道少但质量高，适合作为主源补充 |
| IPTV-org 台湾 | `https://raw.githubusercontent.com/iptv-org/iptv/master/streams/tw.m3u` | 56 | 68% | 台港澳频道 |
| IPTV-org 香港 | `https://raw.githubusercontent.com/iptv-org/iptv/master/streams/hk.m3u` | 25 | 24% | 频道少、可用率一般 |
| IPTV-org 中国 | `https://raw.githubusercontent.com/iptv-org/iptv/master/streams/cn.m3u` | 510 | 24% | 数量多但失效比例高 |

> 直播源变动频繁，建议每 1–2 个月重新跑一次检测脚本（见下），把可达率明显下降的源换掉。

## 三、自测工具

仓库自带一个轻量检测脚本：

```bash
node scripts/check-live-source.mjs <m3u-url> [抽样数量]
# 例：
node scripts/check-live-source.mjs https://raw.githubusercontent.com/vbskycn/iptv/master/tv/iptv4.m3u 30
```

输出频道总数、HTTP/HTTPS 数量、抽样可达率与失败示例，用来在写进配置前快速判断一个列表是否值得添加。

## 四、常见问题

- **频道点开一直转圈**：多为源站限流、下线或运营商封锁。先在 `/live` 页用「测活」批量检测，再决定是否保留该源。
- **部分频道只有声音没有画面**：源本身是 hls 的分片异常，换同频道其它来源（本仓库支持多源同名聚合）即可。
- **m3u8 是 http 明文**：LibreTV 会通过 `/api/live/stream` 服务端代理转发，不会触发浏览器的混合内容拦截；但要求服务端本身能访问该地址。
- **频道数量与列表不符**：`/live` 页显示的是合并去重后的频道，同一频道来自多个源时只展示一次。
- **节目单为空**：只有配置了 `epg` 且该 XMLTV 地址可访问时才展示节目单。
